Prototype - XR Bootcamp

ACcessories shop website prototype in MR

ABOUT

The Mixed Reality Jewelry Shop concept offers an immersive and interactive shopping experience, allowing users to explore and try on rings in a mixed reality environment.

Year

2025

Client

XR Bootcamp

Description

The Mixed Reality Jewelry Shop concept offers an immersive and interactive shopping experience, allowing users to explore and try on rings in a virtual environment. A virtual jewelry box appears in front of the user, and when opened, a UI displaying various ring designs, materials, prices, and descriptions appears beside it. Users can swipe through different designs using hand gestures, instantly updating the model shown to match the selected option. The interface provides detailed information on each ring, including material options and pricing, giving the user full control over their selection.

Once a design is chosen, users can physically try on the ring by holding it in the virtual space and placing it on their finger, simulating a real-world jewelry fitting experience. If the user is satisfied with the ring, they can purchase it directly through the UI. Upon closing the box, everything resets, offering a seamless and engaging shopping experience. This prototype uses high-quality 3D jewelry models and mixed reality SDKs to deliver an authentic and interactive environment, bringing the virtual jewelry shopping experience to life.
