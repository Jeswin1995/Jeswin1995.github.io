Digital twin - Institute of Multiphase Flows

Remote controllable digital twin of reactor

ABOUT

This project demonstrates how to use m2mqtt, WorldLocking tools, and Microsoft Hololens 2 to display a 3D model of a chemical reactor setup and control the same reactor using a MQTT server, ThingSpeak.

Year

2023

Client

Institute of multiphase flows
(Hamburg University of Technology)

Description

The Augmented Reality Chemical Reactor Setup is an innovative mixed reality application developed for Microsoft HoloLens 2, designed to visualize and control a chemical reactor in real-time using MQTT communication. This project integrates m2mqtt, ThingSpeak IoT platform, and WorldLocking tools to provide a stable and interactive 3D representation of the reactor setup. Users can scan QR codes to align the virtual reactor with the physical environment and interact with it through intuitive UI elements, such as buttons, sliders, and tooltips, built with MRTK (Mixed Reality Toolkit). The PiXYZ plugin was used to optimize and import CAD models, ensuring smooth performance on HoloLens 2. By leveraging holographic remoting, developers can preview and fine-tune interactions in real time, enhancing the development workflow.

The application establishes seamless communication between HoloLens 2 and the ThingSpeak MQTT broker, allowing real-time monitoring and remote control of the reactor. The m2mqtt library facilitates two-way communication, enabling the system to receive sensor updates and send control commands. The project also features P&ID (Piping and Instrumentation Diagram) visualization, internal component display, and interactive tooltips, enhancing user understanding of the chemical process. Built for Universal Windows Platform (UWP), the application was deployed using Visual Studio with ARM64 architecture to ensure optimal performance. This project demonstrates the potential of augmented reality and IIoT (Industrial Internet of Things) in revolutionizing industrial process control, bridging the gap between physical and digital environments for more intuitive and efficient operations.
